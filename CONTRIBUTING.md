# Contributing

Bug reports, accessibility observations, pedagogical suggestions, and code contributions are welcome.

When reporting an interface bug, please include:

- browser and operating system;
- approximate screen size or device model;
- mode and operation being used;
- the sequence of clicks that produced the issue;
- a screenshot when possible.

Before submitting interface changes, run the UI regression harness described in `docs/UI_TESTING.md` and confirm that the supported mobile and desktop workflows pass.
